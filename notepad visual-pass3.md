## Readability

Readability is now more important than aesthetics.

Review EVERY screen manually.

Inspect EVERY text element.

Assume you are performing a professional accessibility audit.

There must NEVER exist:

- black text on dark backgrounds

- low-contrast helper text
- unreadable placeholders
- faded captions
- invisible timestamps
- weak chart labels
- difficult table values
- subtle legends
- inaccessible secondary buttons

If there is any doubt between subtlety and readability,

ALWAYS choose MORE contrast.

Do not be afraid of darker text.

Do not leave low-contrast typography anywhere.

WCAG AA compliance is mandatory.
